V0.5 Control Rules

1. Matching the broad function alone is not enough.

2. The learner must perform the required function + intent + information target.

3. A related but different question must not unlock ADVANCE.

4. Natural paraphrases with the same communicative intent should pass.

5. Statements cannot satisfy a task requiring a question.

6. The State Engine — not the learner and not the AI — controls progression.
