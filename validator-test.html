🧠 SPEAK Semantic Validator V0.1

This prototype tests whether the learner has completed the current communication task before the conversation is allowed to advance.

Scenario: Booking a Tour
⚪ WAITING — enter a learner response.
State Engine
currentTask: ASK_DESTINATION
expectedFunction: ASK_QUESTION
expectedInformation: DESTINATION
hintLevel: 0
advance: false
Validator rule

🟢 PASS — the learner completes the current communication task. Only PASS can unlock ADVANCE.

🟡 NEEDS SUPPORT — the response is understandable but does not complete the current task. Give Hint 1 → Hint 2 → Hint 3 progressively.

🟠 UNCERTAIN — the transcript is too unclear to judge safely. Ask the learner to say it again. Do not increase the hint level.

Important: the validator checks task achievement. It does not assume that a Browser Speech transcript is an exact record of the learner's grammar.

Prototype only. No Gemini API is used on this page. No learner score is produced.
