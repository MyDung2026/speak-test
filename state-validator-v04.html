V0.4 Control Rules

🟢 PASS — Function + Intent + Information must all match the current task.

🟡 NEEDS SUPPORT — stay on the current task and use Hint 1 → Hint 2 → Hint 3.

🟠 UNCERTAIN — ask the learner to try again without increasing the hint level.

🔒 STATE ENGINE OWNS ADVANCE — only the State Engine can unlock the next task.

🛡️ INTENT GUARD — a sentence cannot pass simply because it contains a relevant word. For example, “How much is the hotel?” is a PRICE question, not an accommodation-preference question.
