🧠 SPEAK State Engine V0.2

This prototype tests whether the system can keep the learner on the current communication task and move through a controlled sequence without skipping tasks.
Scenario: Booking a Tour
Student role: Travel Agent
AI role: Tourist
⚪ WAITING — complete the current communication task.
State Engine rules

🟢 PASS — only PASS unlocks ADVANCE.

🟡 NEEDS SUPPORT — remain on the same task. Hint 1 → Hint 2 → Hint 3 progressively.

🟠 UNCERTAIN — ask the learner to say it again. Do not increase the hint level.

🔒 Task Lock — the next task cannot open until the current task has been achieved.

🧱 Student-Task Firewall — the system must never complete the student's required communication task for them.
