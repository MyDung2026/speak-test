V0.3 Control Rules

🟢 PASS — the learner has achieved the required communication function and information goal.

🟡 NEEDS SUPPORT — the learner has not achieved the current task. Stay on the same task and provide progressive support.

🟠 UNCERTAIN — the response is empty, unclear, or cannot safely be interpreted. Ask the learner to try again. Do not increase the hint level.

🔒 STATE ENGINE OWNS ADVANCE — the validator may recommend PASS, but only the State Engine can unlock the next task.

🚫 NO KEYWORD-ONLY PASS — a relevant word alone is not enough. The response must perform the required communication function.
